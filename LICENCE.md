## 🧩 About

**Raft desktop helper** is a curated list of Raft open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, raft position display
- **Quality-of-Life Helpers** — crafting catalog, item manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Resource Tracker — monitor nearby materials and debris
- Raft Position Display — visualize drift and heading notes
- Weather Notes — track storm and shark activity patterns
- Playback Speed — adjust helper refresh rate for study

### 🎨 Catalog & Cosmetics
- Item Catalog — browse crafting recipes, tools, and buildables
- Custom Skin Notes — organize character cosmetics
- Inventory Overview — improved visibility of storage layouts

### 🏋️ Build Layout
- Build Mode Notes — segment study on any raft layout
- Placement Helper — manual grid alignment notes
- Chain Crafting Notes — plan multi-step crafting sequences

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"Raft.exe"` | Target process |
